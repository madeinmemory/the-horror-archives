# The Horror Archives

The Horror Archives is an interactive web archive exploring horror media, folklore, internet horror, liminal spaces, and fictional entities.

The project is organized into several archive directories, including:

- Backrooms
- SCP Foundation
- Creepypasta
- Entities & Legends
- Horror Games

Users can browse categories, select individual records, and view dynamically displayed information through an archive-inspired interface.

## Project History

The Horror Archives actually started as **Broken But Beautiful Archives**, a site I made for a fictional world and story I had been creating. It was originally a place to keep track of its characters, locations, creatures, and other pieces of the world.

I eventually decided to retire _Broken But Beautiful_, but I still really liked the archive website I had built for it and didn't want to throw away all of that work. So instead, I redesigned the site into **The Horror Archives**.

Now the archive is a collection of some of my favorite horror stories, games, internet legends, creatures, and fictional worlds. It includes sections for things like the Backrooms, SCP Foundation, creepypastas, entities and urban legends, and horror games, with individual records covering the places, creatures, characters, and stories found within them. I will add onto this project the more I find horror I enjoy.

The original code and structure from Broken But Beautiful still make up the foundation of the site, but it has been redesigned and expanded for its new purpose.
